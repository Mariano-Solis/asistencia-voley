- El piloto usa `institution_id` en categorías, jugadores, jornadas y asistencia, claves foráneas compuestas, funciones `pilot_member` y RLS. La prueba de UI del helper usa cliente simulado. Son pruebas de regresión, no JWT Auth/PostgREST real.
- Cuando se agregue un módulo persistido: migración comercial reversible con guarda que descarte `public.profiles` (esquema original), RLS de lectura/escritura por membresía y licencia, rol para escritura, FK compuesta institucional, Storage privado si aplica y pruebas SQL positivas/negativas; luego prueba con dos JWT auténticos antes de aprobarlo.
